# نصب و راه‌اندازی

برای اجرای پروژه bale_3d_bot باید مراحل زیر را طی کنید:

## پیش‌نیازها

- نصب Node.js و npm (در ترموکس می‌توانید با دستور زیر نصب کنید):  
  ```bash
  pkg install nodejs
دسترسی ترموکس به حافظه (فقط در اندروید):
termux-setup-storage
کلون کردن مخزن
git clone <آدرس-مخزن>
cd bale_3d_bot
نصب وابستگی‌ها
npm install
اجرای پروژه
npm run dev -- -H 0.0.0.0
با این دستور، سرور توسعه روی تمام آی‌پی‌های موجود اجرا می‌شود و می‌توانید از دستگاه دیگر در شبکه نیز به آن دسترسی داشته باشید.
