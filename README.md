تبدیل تصاویر دو بعدی به مدل‌های سه‌بعدی: یک راهکار کامل مبتنی بر وب، پرداخت آنلاین و بسترهای پیام‌رسان

## چکیده

در این مقاله، یک **پلتفرم جامع و عملیاتی** برای تبدیل تصاویر دو بعدی (عکس‌ها) به مدل‌های سه‌بعدی (OBJ) معرفی می‌شود. این سیستم با بهره‌گیری از الگوریتم‌های پردازش تصویر، نقشه ارتفاع (Height Map) و بهینه‌سازی‌های متنوع، امکان دریافت تصویر از کاربر، استخراج عمق و تولید مدل سه‌بعدی را فراهم می‌کند. همچنین با اتصال به **پیام‌رسان بله** (Bale) و ارائه **درگاه پرداخت آنلاین**، تجربه‌ای کامل از سفارش، پرداخت و دریافت مدل نهایی در اختیار کاربران قرار می‌گیرد. این پروژه با رویکرد **کد باز** و **مستقر بر بستر Vercel** طراحی شده است و می‌تواند به عنوان یک کسب‌وکار آنلاین در زمینه مدل‌سازی سه‌بعدی مورد استفاده قرار گیرد.

## ۱. مقدمه

با گسترش فناوری‌های سه‌بعدی و چاپ سه‌بعدی، نیاز به تبدیل اشیاء دو بعدی (مانند عکس‌ها، طرح‌ها و تصاویر هنری) به مدل‌های سه‌بعدی بیش از پیش احساس می‌شود. در این راستا، **سیستم 2D-to-3D Converter** ارائه شده در این مقاله، یک راهکار کامل از ابتدا تا انتها برای کاربران عادی و کسب‌وکارها فراهم می‌کند.

### اهداف اصلی پروژه:
- تبدیل خودکار تصاویر دو بعدی به مدل‌های سه‌بعدی با فرمت OBJ.
- ارائه یک رابط کاربری ساده (وب‌اپ) برای آپلود تصویر و مشاهده مدل.
- اتصال به ربات پیام‌رسان بله جهت دریافت سفارش از طریق پیام‌رسان.
- پیاده‌سازی درگاه پرداخت آنلاین (کیف پول بله) برای دریافت وجه.
- استقرار آسان روی سرویس‌های ابری مانند Vercel.

## ۲. معماری سیستم

سیستم از چهار لایه اصلی تشکیل شده است:

1. **لایه نمایش (Frontend)** : یک صفحه وب ساده با قابلیت آپلود عکس، نمایش حالت سیمی مدل (wireframe) و دکمه پرداخت.
2. **لایه API (Backend)** : توابع سرورلس (Serverless Functions) در Next.js که وظیفه دریافت تصویر، فراخوانی موتور تبدیل، مدیریت پرداخت و ارتباط با پیام‌رسان بله را بر عهده دارند.
3. **موتور تبدیل سه‌بعدی** : اسکریپت پایتون (`engine_3d.py`) که با استفاده از کتابخانه‌های `Pillow` و `NumPy` عملیات تبدیل را انجام می‌دهد.
4. **بستر پیام‌رسان بله** : رباتی که از طریق وب‌هوک (Webhook) به سرور متصل می‌شود و قابلیت دریافت عکس و ارسال مدل نهایی را فراهم می‌کند.

## ۳. الگوریتم تبدیل 2D به 3D

### ۳.۱. نقشه ارتفاع (Height Map)

اصلی‌ترین روش استفاده شده، **نقشه ارتفاع** است. در این روش، شدت روشنایی هر پیکسل (luminance) مستقیماً به ارتفاع (Z) تبدیل می‌شود:

```python
depth = (1.0 - luminance) * max_height
```

· نقاط تیره‌تر (مثلاً بدن مگس) → ارتفاع بیشتر
· نقاط روشن‌تر (زمینه) → ارتفاع نزدیک به صفر

۳.۲. پیش‌پردازش تصویر

· تبدیل به فضای رنگی خاکستری با فرمول استاندارد ITU-R BT.601:
  ```
  Y = 0.299*R + 0.587*G + 0.114*B
  ```
· فیلتر میانه (Median Filter) با کرنل ۳×۳ برای حذف نویزهای نقطه‌ای (ذرات گرد و غبار روی عکس).
· یکسان‌سازی پس‌زمینه با آستانه‌گذاری (thresholding): پیکسل‌های روشن‌تر از ۰.۸۵ ارتفاع صفر می‌گیرند.
· تقویت لبه‌ها (Edge Boost) با عملگر Sobel برای برجسته‌سازی جزئیات (بال، پاها و لبه‌های شیء).

۳.۳. خروجی OBJ

مدل نهایی به فرمت استاندارد OBJ ذخیره می‌شود. رئوس (vertices) شامل سه مختصه X, Y, Z هستند که X و Y در بازه [0,1] نرمال شده‌اند (منطبق با ابعاد تصویر) و Z از نقشه ارتفاع محاسبه می‌شود.

مثلث‌بندی به صورت شبکه منظم (grid mesh) با انتخاب کوتاه‌ترین قطر برای هر سلول انجام می‌شود تا وزن یال‌ها مینیمم شود. همچنین جهت نرمال‌ها (normal vectors) با محاسبه مساحت علامت‌دار (signed area) تصحیح می‌شود تا همه نرمال‌ها به سمت بیرون مدل باشند.

۴. پیاده‌سازی فنی

۴.۱. تکنولوژی‌های استفاده شده

بخش فناوری دلیل انتخاب
فرانت‌اند React (Next.js) رندر سمت سرور، بهینه‌سازی، و استقرار آسان
بک‌اند Next.js API Routes توابع سرورلس، هماهنگ با فرانت‌اند
پردازش تصویر Python + NumPy + Pillow سرعت بالا، کتابخانه‌های قدرتمند
پیام‌رسان Bale Bot API پشتیبانی رسمی از وب‌هوک و ارسال فایل
پرداخت کیف پول بله (Bale Pay) یکپارچگی با پلتفرم، امنیت بالا
استقرار Vercel پشتیبانی از Next.js و توابع پایتون

۴.۲. ساختار پروژه

```
.
├── pages/
│   ├── api/
│   │   ├── uploadImage.js     # دریافت تصویر و فراخوانی پایتون
│   │   ├── payment.js         # درگاه پرداخت
│   │   └── webhook.js         # وب‌هوک ربات بله
│   ├── index.js               # صفحه اصلی (آپلود و پرداخت)
│   └── payment.js             # صفحه پرداخت
├── public/
│   ├── models/                # خروجی مدل‌های OBJ
│   └── preview.html           # نمایش سه‌بعدی مدل با Three.js
├── engine_3d.py               # موتور تبدیل پایتون
├── requirements.txt           # وابستگی‌های پایتون
├── vercel.json                # پیکربندی استقرار
└── README.md                  # این مستند
```

۴.۳. فراخوانی پایتون از Node.js

در API Routes، از ماژول child_process برای اجرای اسکریپت پایتون استفاده می‌شود:

```javascript
const { exec } = require('child_process');
const { promisify } = require('util');
const execPromise = promisify(exec);

const { stdout, stderr } = await execPromise(
  `python3 engine_3d.py "${tempImagePath}" "${outputObjPath}"`
);
```

۴.۴. ارتباط با بله

ربات بله با استفاده از وب‌هوک (Webhook) به آدرس /api/webhook متصل می‌شود. هر پیام حاوی عکس، پس از دریافت، تصویر دانلود شده و به موتور پایتون ارسال می‌گردد. سپس مدل نهایی با استفاده از متد sendDocument به کاربر بازگردانده می‌شود.

ثبت وب‌هوک:

```
https://api.bale.ai/bot<TOKEN>/setWebhook?url=https://your-domain.vercel.app/api/webhook
```

۴.۵. پرداخت با کیف پول بله

در صورت پرداخت موفق، ولت واقعی (WALLET-as6NfAMYM6r5ZKUv) وجه را دریافت می‌کند و در پاسخ API یک تراکنش موفق ثبت می‌شود.

۵. بهینه‌سازی‌ها و نکات فنی

۵.۱. کاهش مصرف حافظه در Termux

با محدودیت حافظه در اندروید، حداکثر ابعاد تصویر به 300×300 کاهش یافته است (قابل تنظیم در engine_3d.py). این کار تعداد رئوس را به حدود ۹۰,۰۰۰ می‌رساند و از کرش برنامه جلوگیری می‌کند.

۵.۲. رفع نویز میله‌ای

استفاده از فیلتر میانه (Median Filter) و سپس فیلتر گوسین سبک باعث حذف نویزهای نقطه‌ای و تصادفی می‌شود بدون اینکه لبه‌ها تار شوند.

۵.۳. بهترین پارامترها برای تبدیل

پارامتر مقدار پیش‌فرض تأثیر
max_height 0.28 حداکثر ارتفاع برجستگی
edge_boost 0.3 میزان تقویت لبه‌ها
bg_threshold 0.85 حذف زمینه روشن‌تر از این مقدار
gamma 1.2 تصحیح کنتراست (بیشتر = حساسیت کمتر)
smooth_sigma 0.4 هموارسازی نهایی

۶. نحوه استفاده و راه‌اندازی

۶.۱. پیش‌نیازها

· Node.js 18+
· Python 3.9+
· حساب کاربری در Vercel و GitHub

۶.۲. مراحل نصب و اجرا

```bash
# 1. clone مخزن
git clone https://github.com/your-repo/bale-3d-bot.git
cd bale-3d-bot

# 2. نصب وابستگی‌های Node.js
npm install

# 3. نصب وابستگی‌های پایتون
pip install -r requirements.txt

# 4. تنظیم متغیرهای محیطی (ایجاد فایل .env.local)
BOT_TOKEN=your_bot_token
WALLET_ID=WALLET-as6NfAMYM6r5ZKUv

# 5. اجرا در محیط لوکال
npm run dev
```

۶.۳. استقرار روی Vercel

```bash
vercel --prod
```

سپس به داشبورد Vercel رفته و متغیرهای محیطی را در Settings > Environment Variables تنظیم کنید.
