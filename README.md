# README.md جامع و مفصل پروژه bale_3d_bot

```markdown
# پروژه bale_3d_bot

## معرفی
پروژه bale_3d_bot یک سامانه تبدیل تصاویر دو بعدی به مدل‌های سه‌بعدی است که با هدف ارائه یک راهکار کاربردی در زمینه پردازش تصویر و تبدیل آن به مدل‌های سه‌بعدی سیمی به صورت آنلاین و آفلاین توسعه یافته است. این پروژه با استفاده از زبان Python برای پردازش مدل و Next.js برای فرانت‌اند ساخته شده است.

---

## اهداف پروژه
- تبدیل عکس دو بعدی به مدل سه‌بعدی مشبک (wireframe)
- نمایش پیش‌نمایش سیمی مدل سه‌بعدی برای کاربران قبل از پرداخت
- استفاده از الگوریتم‌های بهینه برای تولید سریع مدل سه‌بعدی
- ادغام با درگاه پرداخت بله برای امکان پرداخت آنلاین
- ارائه لینک دانلود مدل کامل و با کیفیت پس از پرداخت موفق

---

## پیش‌نیازها
- Python 3.7 یا بالاتر
- Node.js 14 یا بالاتر
- بسته‌های Python:
  - numpy
  - pillow
- بسته‌های npm:
  - next
  - react
  - three
  - formidable

---

## نصب و راه‌اندازی

### بخش Python
1. نصب بسته‌ها:
   ```bash
   pip install numpy pillow
   ```
2. اجرای تست مدل:
   ```bash
   python3 test.py
   ```
3. ذخیره مدل‌ها در پوشه `models/` با نام استاندارد `*.obj`

### بخش Next.js
1. نصب وابستگی‌های npm:
   ```bash
   npm install
   ```
2. اجرای سرور توسعه:
   ```bash
   npm run dev
   ```
3. باز کردن مرورگر و مراجعه به:
   ```
   http://localhost:3000
   ```

## جزئیات طراحی و پیاده‌سازی

### تولید مدل سه‌بعدی

- الگوریتم تجمیع ذوزنقه‌های کوچک به ذوزنقه بزرگ به صورت منحنی کوبیک  
- بر اساس درونیابی کوبیک نقاط کنترل (Bezier curves)  
- تولید مش (mesh) با مثلث‌بندی دقیق بین منحنی‌ها  
- ذخیره متن‌باز در فرمت OBJ قابل خواندن توسط نرم‌افزارهای سه‌بعدی

### پیش‌نمایش مدل سه‌بعدی

- استفاده از کتابخانه Three.js برای بارگذاری و رندر مدل OBJ  
- نمایش مدل به صورت wireframe (سیمی) جهت بازخورد سریع کاربر  
- رندر سه‌بعدی قابل چرخش برای بررسی بهتر مدل

### مدیریت آپلود و ذخیره فایل

- بر پایه Next.js API Routes و کتابخانه formidable  
- ذخیره امن فایل در پوشه `public/models`  
- ساخت فایل فلگ `.ready` برای علامت گذاری آماده بودن مدل

### روند پرداخت

- شبیه‌سازی اولیه با دکمه پرداخت  
- امکان اتصال به درگاه پرداخت بله به صورت API واقعی  
- پس از پرداخت موفق لینک مدل برای دانلود به کاربر داده می‌شود
