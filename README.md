# تبدیل تصاویر دو بعدی به مدل‌های سه‌بعدی
## یک راهکار کامل مبتنی بر وب، پرداخت آنلاین و بستر پیام‌رسان بله

---

## چکیده

در این مقاله، یک **پلتفرم جامع و عملیاتی** برای تبدیل تصاویر دو بعدی (عکس‌ها) به مدل‌های سه‌بعدی (فرمت OBJ) معرفی می‌شود. این سیستم با بهره‌گیری از الگوریتم‌های پردازش تصویر، نقشه ارتفاع پیشرفته و بهینه‌سازی‌های متعدد، امکان دریافت تصویر از کاربر، استخراج عمق هوشمند و تولید مدل سه‌بعدی را فراهم می‌کند. همچنین با اتصال به **پیام‌رسان بله** (Bale) و ارائه **درگاه پرداخت آنلاین**، تجربه‌ای کامل از سفارش، پرداخت و دریافت مدل نهایی در اختیار کاربران قرار می‌دهد. این پروژه با رویکرد **کد باز** و **مستقر بر بستر Vercel** طراحی شده و می‌تواند به عنوان یک کسب‌وکار آنلاین در زمینه مدل‌سازی سه‌بعدی مورد استفاده قرار گیرد.

---

## ۱. مقدمه

با گسترش فناوری‌های سه‌بعدی و چاپ سه‌بعدی، نیاز به تبدیل اشیاء دو بعدی (عکس‌ها، طرح‌ها، تصاویر هنری) به مدل‌های سه‌بعدی بیش از پیش احساس می‌شود. در این راستا، **سیستم 2D-to-3D Converter** ارائه شده در این مقاله، یک راهکار کامل از ابتدا تا انتها برای کاربران عادی و کسب‌وکارها فراهم می‌کند.

### اهداف اصلی پروژه:
- تبدیل خودکار تصاویر دو بعدی به مدل‌های سه‌بعدی با فرمت OBJ.
- ارائه رابط کاربری ساده (وب‌اپ) برای آپلود تصویر و مشاهده مدل به‌صورت سه‌بعدی.
- اتصال به ربات پیام‌رسان بله جهت دریافت سفارش از طریق پیام‌رسان.
- پیاده‌سازی درگاه پرداخت آنلاین (کیف پول بله) برای دریافت وجه.
- استقرار آسان روی سرویس‌های ابری مانند Vercel.

## ۲. معماری سیستم

سیستم از چهار لایه اصلی تشکیل شده است:

1. **لایه نمایش (Frontend)** : صفحه وب با قابلیت آپلود عکس، نمایش سه‌بعدی مدل (جامد) و دکمه پرداخت.
2. **لایه API (Backend)** : توابع سرورلس (Serverless Functions) در Next.js که وظیفه دریافت تصویر، فراخوانی موتور تبدیل، مدیریت پرداخت و ارتباط با پیام‌رسان بله را بر عهده دارند.
3. **موتور تبدیل سه‌بعدی** : اسکریپت پایتون (`engine_3d.py`) با استفاده از کتابخانه‌های `Pillow`، `NumPy` و `SciPy` که الگوریتم نهایی تبدیل را اجرا می‌کند.
4. **بستر پیام‌رسان بله** : رباتی که از طریق وب‌هوک (Webhook) به سرور متصل می‌شود و قابلیت دریافت عکس و ارسال مدل نهایی را دارد.

## ۳. الگوریتم تبدیل 2D به 3D – نسخه نهایی (پس از بهینه‌سازی‌های گسترده)

پس از آزمون‌های متعدد، تحلیل دقیق کد C# مرجع و بازخوردهای عملی، **فرمول نهایی** که بالاترین کیفیت را در روش‌های سنتی ارائه می‌دهد، به صورت زیر به‌دست آمده است:

### ۳.۱. استخراج روشنایی (Intensity)
برای حفظ اطلاعات کامل تصویر، از **میانگین سه کانال RGB** استفاده می‌شود (نه فقط کانال قرمز و نه لومینانس وزنی):
```python
intensity = (R + G + B) / 3.0   # مقدار 0 تا 1
```

۳.۲. پیش‌پردازش

· فیلتر میانه (Median Filter) با کرنل ۳×۳ برای حذف نویزهای نقطه‌ای (بدون تخریب لبه‌ها).
· یکسان‌سازی پس‌زمینه با آستانه‌گذاری bg_threshold=0.85: پیکسل‌های روشن‌تر از این مقدار ارتفاع صفر می‌گیرند.
· بدون هموارسازی گوسین (چون باعث نابودی لبه‌ها و جزئیات بال می‌شد).

۳.۳. فرمول نهایی ارتفاع – برگرفته از الگوریتم C# مرجع

پس از تحلیل دقیق متد Calculate3DPoint در کد C# شما، فرمول اصلی به صورت زیر است:

```python
r = intensity[y, x]                    # شدت روشنایی (0..1)
angle = (x / width) * 2 * math.pi      # زاویه افقی
depth = r * math.cos(angle)            # عمق در بازه [-1, 1]

X = (x / width) * 2 - 1
Y = (y / height) * 2 - 1
Z = depth                              # بدون فشرده‌سازی
```

نکته مهم: در نسخه‌های قبلی اشتباهاً از sin استفاده شده بود که نتیجه را خراب می‌کرد. فرمول صحیح cos است.

۳.۴. مثلث‌بندی بهینه

· استفاده از مثلث‌بندی Delaunay بر روی نقاط (X,Y) که سطحی صاف و طبیعی ایجاد می‌کند.
· در صورت نبود scipy، fallback به شبکه منظم با انتخاب کوتاه‌ترین قطر.

۳.۵. کاهش رئوس هوشمند (Decimation)

· محاسبه خطای هر رأس: اختلاف Z آن با میانگین Z همسایگانش.
· رئوس با خطای بالا (لبه‌ها، بال، پاها) حفظ می‌شوند.
· رئوس با خطای کم (نواحی صاف) حذف می‌شوند.
· تعداد نهایی رئوس قابل تنظیم است (target_vertices=15000 پیش‌فرض).

۳.۶. مرکزی‌سازی خودکار و حذف رئوس پرت

· محاسبه کرانه‌های مدل (min, max) و انتقال به مرکز کادر.
· حذف رئوس با انحراف معیار بیش از ۳ برابر (پرت‌ها).

۳.۷. تصحیح نرمال‌ها (Outward Normals)

جهت نرمال هر مثلث با محاسبه مساحت علامت‌دار در صفحه XY تصحیح می‌شود تا همگی به سمت بیرون مدل باشند (برای رندر صحیح).

۴. پیاده‌سازی فنی

۴.۱. تکنولوژی‌های استفاده شده

بخش فناوری دلیل انتخاب
فرانت‌اند React (Next.js) رندر سمت سرور، بهینه‌سازی، استقرار آسان
بک‌اند (API) Next.js API Routes توابع سرورلس، هماهنگ با فرانت‌اند
پردازش تصویر Python + NumPy + Pillow + SciPy سرعت بالا، کتابخانه‌های قدرتمند
پیام‌رسان Bale Bot API پشتیبانی رسمی از وب‌هوک، ارسال فایل، کیف پول اختصاصی
پرداخت کیف پول بله (Bale Pay) یکپارچگی با پلتفرم، امنیت بالا
استقرار Vercel پشتیبانی از Next.js و توابع پایتون

۴.۲. ساختار پروژه

```
.
├── pages/

│   ├── models/                # خروجی مدل‌های OBJ
```

۵. بهینه‌سازی‌ها و نکات فنی کلیدی

۵.۱. کاهش مصرف حافظه در Termux

در محیط Termux (اندروید)، حداکثر ابعاد تصویر به 300×300 کاهش یافته است (تعداد رئوس ~۹۰,۰۰۰). این کار از کرش برنامه جلوگیری می‌کند.

۵.۲. رفع نویز میله‌ای

استفاده از فیلتر میانه ۳×۳ (بدون فیلتر گوسین) باعث حذف نویزهای نقطه‌ای بدون تخریب لبه‌ها می‌شود.

۵.۳. بهترین پارامترها برای تبدیل

پارامتر مقدار پیش‌فرض تأثیر
max_res 400 حداکثر ابعاد تصویر (تعیین حجم مدل)
target_vertices 15000 تعداد نهایی رئوس (تعادل کیفیت/حجم)
bg_threshold 0.85 حذف زمینه روشن‌تر از این مقدار
remove_outliers True حذف رئوس پرت (انحراف معیار ۳ برابر)

۵.۴. وابستگی‌ها

· حداقل وابستگی: numpy, Pillow
· اختیاری (برای کیفیت بهتر): scipy (برای Delaunay و درون‌یابی)

۷.۲. مراحل نصب و اجرا در لوکال (Termux یا هر سیستم)

```bash
# 1. clone مخزن
git clone https://github.com/your-repo/bale-3d-bot.git
cd bale-3d-bot

# 2. نصب وابستگی‌های Node.js
npm install

# 3. نصب وابستگی‌های پایتون
pip install -r requirements.txt

# 4. تنظیم متغیرهای محیطی (ایجاد فایل .env.local)
BOT_TOKEN=your_bot_token_here
WALLET_ID=WALLET-as6NfAMYM6r5ZKUv

# 5. اجرا در محیط لوکال
npm run dev
```

سپس به آدرس http://localhost:3000 رفته، تصویر را آپلود کرده و مدل سه‌بعدی را مشاهده کنید.

۷.۳. استقرار روی Vercel

```bash
vercel --prod
```

متغیرهای محیطی را در داشبورد Vercel (Settings > Environment Variables) تنظیم کنید.
