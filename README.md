# پروژه bale_3d_bot

## معرفی  
این پروژه یک سامانه تبدیل تصاویر دو بعدی به مدل‌های سه‌بعدی است که با استفاده از پایتون برای پردازش مدل و Next.js برای بخش فرانت‌اند توسعه یافته است.  
امکان آپلود تصویر، پردازش مدل، پیش‌نمایش مدل سیمی، پرداخت و دریافت مدل نهایی فراهم شده است.

---

## پیش‌نیازها

- نصب Python 3.7+ و کتابخانه‌های مورد نیاز:
  ```bash
  pip install numpy pillow requests
  ```
  
- نصب Node.js و npm برای فرانت‌اند Next.js:
  ```bash
  npm install
  ```

---

## راه‌اندازی

### اجرای تست مدل پایتون

- قرار دادن تصویر ورودی `test_image.jpg` در پوشه ریشه پروژه  
- اجرای تست:
  ```bash
  python3 test.py
  ```

### اجرای فرانت‌اند

- اجرای سرور توسعه Next.js:
  ```bash
  npm run dev
  ```
- دسترسی از مرورگر به:
  ```
  http://localhost:3000
  ```

---

## نحوه استفاده

1. در صفحه وب، تصویر دو بعدی را آپلود کن.  
2. پس از تبدیل، مدل سه‌بعدی به صورت سیمی پیش‌نمایش داده می‌شود.  
3. در صورت تایید، عملیات پرداخت شروع و لینک دانلود مدل نهایی فعال می‌شود.

## نکات مهم

- محدودیت حافظه ترموکس را در نظر بگیر و حجم تصویر ورودی را پیش از آپلود کم کن.  
- دسترسی حافظه ترموکس را فعال کن:
  ```bash
  termux-setup-storage
  ```
- هشدارهای کش Webpack در ترموکس را با تنظیمات `watchOptions` کاهش بده.

---

## رفع خطاهای رایج

- درباره خطای دسترسی:
  در `next.config.js` این بخش را اضافه کن:
  ```js
  module.exports = {
    webpack: (config, { dev }) => {
      if (dev) {
        config.watchOptions = {
          poll: 1000,
          aggregateTimeout: 300,
          ignored: ['/data/**'],
        };
      }
      return config;
    }
  };
  ```
- خطای آپلود با formidable:
  مطمئن شو نسخه جدید آن و کد ایمپورت با:
  ```js
  import { IncomingForm } from "formidable";
  const form = new IncomingForm();
  ```
  استفاده شده است.
