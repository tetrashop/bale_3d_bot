در ادامه یک نمونه کامل و استاندارد فایل README.md به زبان فارسی برای پروژه شما آورده‌ام که شامل معرفی، نصب، اجرا، رفع مشکلات رایج و توضیحات لازم است:

## راهنمای نصب

1. نصب [Node.js](https://nodejs.org/) و npm  
   (داخل ترموکس: `pkg install nodejs`)

2. کلون کردن مخزن پروژه  
   ```bash
   git clone <آدرس-مخزن>
   cd bale_3d_bot
   ```

3. نصب وابستگی‌ها  
   ```bash
   npm install
   ```

4. اجرای پروژه  
   ```bash
   npm run dev -- -H 0.0.0.0
   ```

---

## استفاده

- در مرورگر اندروید یا کامپیوتر آدرس  
  ```
  http://localhost:3000
  ```
  (یا اگر پورت 3000 گرفته شده بود، مثلا 3001) باز کنید.

- تصویر دوبعدی خود را آپلود کنید و خروجی سه‌بعدی را دریافت نمایید.

## رفع مشکلات رایج

- **خطاهای دسترسی (EACCES) به مسیرهای سیستمی**  
  ترموکس به صورت پیش‌فرض اجازه دسترسی به همه مسیرها را ندارد. از دستورات زیر استفاده کنید:  
  ```bash
  termux-setup-storage
  chmod -R u+rw ~/bale_3d_bot
  ```
  سپس ترموکس را ببندید و دوباره باز کنید.

- **خطا در مشاهده تغییرات فایل‌ها (Watchpack errors)**  
  به دلیل محدودیت‌های اندروید، بهتر است polling را در تنظیمات webpack فعال کنید (بصورت زیر در `next.config.js`):  
  ```js
  module.exports = {
    webpack: (config, options) => {
      if (options.dev) {
        config.watchOptions = {
          poll: 1000,
          aggregateTimeout: 300,
        };
      }
      return config;
    },
  };
  ```

- **پورت مورد نظر در use بودن**  
  پروژه به صورت خودکار پورت‌های بعدی (مثلا 3001) را استفاده می‌کند. کافیست مرورگر را با پورت جدید باز کنید.
