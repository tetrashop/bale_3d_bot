# پروژه bale_3d_bot

## معرفی
این پروژه یک سامانه تبدیل تصاویر دو بعدی به مدل‌های سه بعدی است که با استفاده از پایتون و Next.js توسعه یافته است.  
امکان آپلود عکس، پردازش مدل سه بعدی، پیش‌نمایش مدل سیمی قبل از پرداخت و مدیریت ساده پرداخت نیز فراهم شده است.

---

## پیش‌نیازها
- نصب Python 3 (نسخه 3.7 به بالا پیشنهاد می‌شود)  
- نصب Node.js و npm برای بخش فرانت‌اند (Next.js)  
- نصب کتابخانه‌های پایتون:
  ```bash
  pip install numpy pillow requests
  ```
- نصب بسته‌های npm:
  ```bash
  npm install
  ```

---

## راه‌اندازی

### اجرای سمت سرور پایتون (پردازش مدل)

1. قرار دادن تصویر تست `test_image.jpg` در پوشه پروژه  
2. اجرای تست مدل:
   ```bash
   python3 test.py
   ```
   این تست مدل را تولید، بارگذاری، پرداخت شبیه‌سازی و دسترسی به فایل را بررسی می‌کند.

### اجرای فرانت‌اند (Next.js)

- اجرای سرور توسعه Next.js:
  ```bash
  npm run dev
  ```
- دسترسی به آدرس [http://localhost:3000](http://localhost:3000) برای تست اپلیکیشن

---

## نحوه استفاده

1. در صفحه اصلی، تصویر دو بعدی خود را آپلود نمایید.  
2. بعد از آپلود، مدل سه‌بعدی به صورت سیمی (wireframe) پیش‌نمایش داده می‌شود.  
3. در صورت تایید، می‌توانید عملیات پرداخت را انجام دهید و مدل نهایی را دریافت کنید.

## رفع مشکلات رایج

- **خطاهای دسترسی (EACCES)**  
  در ترموکس با دستور زیر به ترموکس اجازه دسترسی به حافظه بدهید:
  ```bash
  termux-setup-storage
  ```
- **خطاهای مربوط به Webpack Watchpack**  
  در `next.config.js` تنظیمات `watchOptions` را به این صورت اضافه کنید:
  ```js
  module.exports = {
    webpack: (config, { dev }) => {
      if (dev) {
        config.watchOptions = {
          poll: 1000,
          aggregateTimeout: 300,
        };
      }
      return config;
    },
  };
  ```
- **مشکل اتصال API یا ارسال درخواست‌ها**  
  بررسی کن APIها (`/api/checkReady` و `/api/convert`) به درستی اجرا می‌شوند و مسیرها و نام فایل‌ها صحیح است.
