## چکیده و معرفی

پروژه **تبدیل تصاویر دو بعدی به مدل‌های سه‌بعدی** یک پلتفرم کامل وب‌محور است که به کاربران امکان می‌دهد با آپلود یک تصویر معمولی (JPEG/PNG)، مدل سه‌بعدی با فرمت OBJ دریافت کنند. این سیستم از یک ربات در پیام‌رسان بله، درگاه پرداخت آنلاین و نمایشگر تعاملی Three.js پشتیبانی می‌کند و روی بستر Vercel مستقر شده است.

در طول توسعه، بیش از ۱۰ الگوریتم مختلف پیاده‌سازی و آزمایش شدند: از نقشه ارتفاع خطی ساده تا نگاشت‌های استوانه‌ای و کروی و حتی روش‌های مبتنی بر حجم (مانند کد اصلی C# کاربر). در نهایت، با توجه به محدودیت‌های محیط اجرا (Termux روی گوشی‌های اندروید، عدم دسترسی به GPU و اینترنت پایدار)، **روش مجسمه برجسته (Relief Sculpture – Height Map خطی)** به عنوان **بهره‌ورانه‌ترین، پایدارترین و بدون وابستگی‌ترین راهکار** انتخاب شد. این روش خروجی قابل چاپ سه‌بعدی (صفحه تخت با برجستگی) ارائه می‌دهد و در Termux بدون کرش اجرا می‌شود.

## سیر تکامل الگوریتم‌ها (گام به گام)

در این بخش، تمام روش‌هایی که طی ماه‌ها تلاش پیاده‌سازی شدند، به ترتیب زمانی و با ذکر فرمول، نقاط قوت و ضعف شرح داده می‌شود.

### گام ۱: نقشه ارتفاع خطی (Linear Height Map) – روش پایه
```python
Z = intensity * max_height
```

· مزایا: بسیار ساده، سریع، بدون وابستگی، بدون نویز.
· معایب: حس سه‌بعدی ضعیف، خروجی صاف (مانند مجسمه برجسته).
· وضعیت: به عنوان پایه حفظ شد.

گام ۲: نگاشت استوانه‌ای (Cylindrical Mapping) – الهام از کد C#

```python
angle = (x / width) * 2π
Z = intensity * cos(angle)
```

· مزایا: ایجاد عمق مثبت و منفی، جدا شدن جسم از صفحه.
· معایب: نویز میله‌ای شدید، نیاز به تنظیم دستی پارامترها.
· وضعیت: رد شد (نویز غیرقابل قبول).

گام ۳: نگاشت کروی با sin (اشتباه تاریخی)

```python
angle = (y / height) * π
Z = intensity * sin(angle) * 0.5
```

· مزایا: هیچکدام.
· معایب: مگس به زمین چسبیده، بریدگی در لبه‌ها، ناپایداری.
· وضعیت: رد قطعی.

گام ۴: نگاشت کروی اصلاح‌شده با cos

```python
angle = (x / width) * 2π
Z = intensity * cos(angle) * max_height
```

· مزایا: حس سه‌بعدی خوب، امکان جداشدن از صفحه.
· معایب: نیاز به scipy برای فیلتر میانه (که در Termux نصب نمی‌شد)، نویز باقی‌مانده، مصرف حافظه بالا.
· وضعیت: رد شد به دلیل مشکلات نصب و پایداری.

گام ۵: روش حجمی (Volumetric Mapping) – منطق C# اصلی با آرایه c

این روش مستقیماً از کد _2dTo3D.cs کاربر ترجمه شد. یک آرایه سه‌بعدی (c) در مختصات استوانه‌ای پر می‌شود و سپس به OBJ تبدیل می‌گردد.

· مزایا: وفاداری کامل به الگوریتم مرجع.
· معایب: بسیار کند، مصرف حافظه‌ی زیاد، خطاهای overflow و division by zero در Termux، عدم پایداری.
· وضعیت: پس از رفع خطاهای اولیه نیز به دلیل پیچیدگی و مصرف منابع کنار گذاشته شد.

گام ۶: مجسمه برجسته بهینه‌شده (Relief Sculpture) – انتخاب نهایی

```python
Z = intensity * max_height   # max_height = 0.28 تا 0.35
X = (x/width)*2 - 1
Y = (y/height)*2 - 1
```

به همراه:

· میانگین سه کانال RGB به عنوان intensity
· فیلتر میانه ۳×۳ (اختیاری، در صورت نصب scipy)
· مرکزی‌سازی خودکار
· مثلث‌بندی شبکه منظم با انتخاب کوتاه‌ترین قطر
· تصحیح نرمال‌ها با مساحت علامت‌دار در XY
· مزایا: بدون نیاز به scipy، کاملاً پایدار در Termux، بدون نویز میله‌ای، خروجی قابل چاپ سه‌بعدی (صفحه تخت)، زمان پردازش ~۱-۲ ثانیه.
· معایب: حس سه‌بعدی کمتر نسبت به روش‌های کروی (اما برای کاربردهای عملی کافی است).
· وضعیت: انتخاب نهایی و توصیه شده.

تحلیل ریاضی و هندسی روش‌ها

۱. نقشه ارتفاع خطی (Relief Sculpture)

```math
Z(x,y) = I(x,y) \cdot H_{max}
```

این مدل یک صفحه مرجع (Z=0) دارد و ارتفاع هر نقطه مستقیماً از شدت روشنایی (I) ناشی می‌شود. از نظر هندسی، شبیه به مجسمه‌سازی برجسته (Bas‑relief) است که در آن جزئیات تصویر به صورت برآمدگی روی زمینه تخت ظاهر می‌شود.

۲. نگاشت استوانه‌ای (Cylindrical)

```math
\begin{cases}
Z = I(x,y) \cdot \cos(\theta) \\
\theta = \frac{x}{W} \cdot 2\pi
\end{cases}
```

هر ستون از تصویر به یک زاویه در استوانه نگاشته می‌شود. عمق (Z) به هر دو شدت روشنایی و زاویه بستگی دارد. نقاط لبه تصویر (θ≈0) عمق مثبت (نزدیک) و نقاط مرکز (θ≈π) عمق منفی (دور) پیدا می‌کنند.

۳. روش مجسمه برجسته (نهایی)

همان فرمول ساده خطی اما با تکنیک‌های پایداری‌سازی (مرکز‌یابی، مقیاس‌بندی مناسب، مثلث‌بندی بهینه). دلیل موفقیت آن حذف توابع مثلثاتی ناپایدار و حفظ سادگی است.

پیاده‌سازی فنی و کدهای نهایی

فایل engine_3d.py – نسخه نهایی (مجسمه برجسته بهینه‌شده)

```python
import os
import sys
import math
import numpy as np
from PIL import Image

class Engine3D:
    def process(self, image_path, output_path="public/models/3d_object.obj", max_res=400):
        # بارگذاری و تبدیل به شدت روشنایی (میانگین RGB)
        img = Image.open(image_path).convert('RGB')
        img.thumbnail((max_res, max_res), Image.Resampling.LANCZOS)
        width, height = img.size
        rgb = np.array(img, dtype=np.float32) / 255.0
        intensity = (rgb[:,:,0] + rgb[:,:,1] + rgb[:,:,2]) / 3.0

        # ساخت رئوس (صفحه تخت با برجستگی)
        max_height = 0.28
        vertices = []
        for y in range(height):
            for x in range(width):
                Z = intensity[y, x] * max_height
                X = (x / width) * 2 - 1
                Y = (y / height) * 2 - 1
                vertices.append((X, Y, Z))

        if len(vertices) < 3:
            return False, None

        # مرکزی‌سازی خودکار
        vertices = np.array(vertices)
        center = vertices.mean(axis=0)
        vertices = vertices - center
        vertices = vertices.tolist()

        # مثلث‌بندی شبکه منظم با کوتاه‌ترین قطر
        w = int(math.sqrt(len(vertices)))
        h = len(vertices) // w
        if w < 2 or h < 2:
            return False, None

        def idx(x, y):
            return y * w + x

        faces = []
        for y in range(h-1):
            for x in range(w-1):
                tl = idx(x, y)
                tr = idx(x+1, y)
                bl = idx(x, y+1)
                br = idx(x+1, y+1)
                a = vertices[tl]; b = vertices[tr]; c = vertices[bl]; d = vertices[br]
                diag1 = ((a[0]-d[0])**2 + (a[1]-d[1])**2 + (a[2]-d[2])**2)**0.5
                diag2 = ((b[0]-c[0])**2 + (b[1]-c[1])**2 + (b[2]-c[2])**2)**0.5
                if diag1 <= diag2:
                    faces.append((tl, bl, tr))
                    faces.append((tr, bl, br))
                else:
                    faces.append((tl, tr, bl))
                    faces.append((tr, br, bl))

        # تصحیح نرمال‌ها (بیرونی)
        def correct_normal(tri):
            a = vertices[tri[0]]
            b = vertices[tri[1]]
            c = vertices[tri[2]]
            area_xy = (b[0]-a[0])*(c[1]-a[1]) - (c[0]-a[0])*(b[1]-a[1])
            if area_xy < 0:
                return (tri[0], tri[2], tri[1])
            return tri
        faces = [correct_normal(f) for f in faces]

        # ذخیره فایل OBJ
        os.makedirs(os.path.dirname(output_path), exist_ok=True)
        with open(output_path, "w", encoding="utf-8") as f:
            f.write("# 3D Model - Relief Sculpture (Final)\n")
            f.write(f"# Vertices: {len(vertices)}, Faces: {len(faces)}\n")
            for v in vertices:
                f.write(f"v {v[0]:.6f} {v[1]:.6f} {v[2]:.6f}\n")
            for face in faces:
                f.write(f"f {face[0]+1} {face[1]+1} {face[2]+1}\n")

        print(f"[OK] Model saved: {len(vertices)} verts, {len(faces)} faces")
        return True, output_path

if __name__ == "__main__":
    if len(sys.argv) >= 2:
        eng = Engine3D()
        out = sys.argv[2] if len(sys.argv) > 2 else "public/models/3d_object.obj"
        eng.process(sys.argv[1], out)
    else:
        print("Usage: python engine_3d.py <image_path> [output.obj]")
```

نتایج و ارزیابی

مقایسه نهایی روش‌ها (بر اساس شرایط واقعی Termux)

معیار نقشه ارتفاع خطی (نهایی) نگاشت استوانه‌ای نگاشت کروی با cos روش حجمی C#
نیاز به scipy خیر بله بله خیر (اما وابستگی‌های دیگر)
نویز میله‌ای ندارد زیاد متوسط بسیار زیاد
زمان پردازش (تصویر ۴۰۰×۴۰۰) ~۱.۵ ثانیه ~۶ ثانیه ~۱۰ ثانیه ~۴۰ ثانیه (و کرش)
پایداری در Termux عالی متوسط کم بسیار ضعیف
مناسب برای چاپ سه‌بعدی بله خیر خیر خیر
حس سه‌بعدی کم متوسط زیاد زیاد (اما بی‌ثبات)

چرا مجسمه برجسته انتخاب نهایی شد؟

1. محدودیت‌های محیط اجرا: Termux روی گوشی، بدون GPU، اینترنت ناپایدار، عدم دسترسی به scipy.
2. پایداری: روش‌های کروی و استوانه‌ای باعث کرش یا مصرف بیش از حد حافظه می‌شوند.
3. کاربرد عملی: خروجی مجسمه برجسته برای چاپ سه‌بعدی (پایه تخت دارد) و نمایش در موزه‌ها مناسب است.
4. سادگی: بدون وابستگی‌های پیچیده، فقط numpy و Pillow.

محدودیت ذاتی (صداقت علمی)

این روش هرگز نمی‌تواند یک مگس واقعی با جزئیات پاها، بال‌ها و چشم‌ها بازسازی کند. برای چنین هدفی تنها راه استفاده از شبکه‌های عصبی عمیق (Deep Learning) مانند One-2-3-45، TripoSR یا Stable Fast 3D است. اما این مدل‌ها نیاز به GPU، حافظه بالا و اینترنت پایدار دارند که در شرایط فعلی در دسترس نیست.
